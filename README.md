# Частотний аналіз літер

Консольна програма для частотного аналізу літер.
Вона підраховує, скільки разів кожна літера зустрічається у введеному тексті, та виводить результат у вигляді стовпчикової діаграми. Великі та маленькі літери рахуються разом.

## Як зібрати

- відкрити файл LetterFrequency.slnx Visual Studio 2026;
- обрати конфігурацію Debug і платформу x64;
- виконати Збірка -> Зібрати рішення (Ctrl+Shift+B).

## Як запустити

Запустити без налагодження (Ctrl+F5) або відкрити зібраний файл LetterFrequency.exe з папки x64\Debug.

## Приклад роботи

Введіть текст для аналізу:

```text
Введіть текст для аналізу: Цуценя вийшло у садок.


а # 1
в # 1
д # 1
е # 1
и # 1
й # 1
к # 1
л # 1
н # 1
о ## 2
с # 1
у ## 2
ц ## 2
ш # 1
я # 1
```

## Що програма не приймає

- порожній рядок;
- рядок, що складається тільки з пробілів;
- текст, який не містить українських літер.
